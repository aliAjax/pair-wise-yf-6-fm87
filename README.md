# 高空外墙施工派工台

端口规划：`5114`

```bash
npm install
npm run dev
```

由家庭维修页扩展而来，预置三支施工队与四项外墙维修工单：

- 派工门槛：每单须配安全员且有两份防坠装备检查，缺任一项整单拒绝，人员、装备与工单数据不改动；人员不足或同队在途则保持待派，同队不得同时承接两单。
- 气象联动：风力达到五级立即停工并冻结进度，天气恢复后须逐单安全复查方可复工。
- 施工进度、费用预估实时统计，全部数据经 localStorage 本地同步，刷新保留。

代码分层：`src/rules.js` 业务规则、`src/flow.js` 流转状态机、`src/storage.js` 浏览器存档、`src/data.js` 预置数据、`src/main.js` 界面编排。
