# 高空外墙施工派工台

端口规划：`5114`

```bash
npm install
npm run dev
```

由家庭维修页扩展而来，核心规则：

- 预置 3 支施工队与 4 项外墙维修工单，可继续登记新工单
- 派工校验：每单须指定安全员并完成两份防坠装备检查，缺任一项整单拒绝，人员、装备与工单保持原状
- 同队不得同时承接两单；作业工人数不足的工单保持待派
- 风力达到 5 级立即停工并冻结进度；天气恢复后须安全员现场确认并重新完成两份防坠装备检查才能复工
- 施工进度按 10% 步进，费用按进度折算已发生金额，统计区同步预估费用
- 所有变更实时写入 localStorage，刷新保留，可一键重置为预置数据

代码分层（分别维护）：

- `src/rules.js` 业务规则：派工/复工校验、风力停工、费用计算（纯函数）
- `src/flow.js` 流转状态：待派 → 待开工 → 施工中 → 风力停工/已完工
- `src/storage.js` 浏览器存档：localStorage 读写与重置
- `src/data.js` 预置数据；`src/main.js` 渲染与事件
